Original source, assets, settings, weights and experiment outputs from both worktrees
were copied here before implementation. `preserved_files.json` records their original
SHA-256 values. No preserved file has been edited. The original main worktree remains
untouched. Active entry points are at the repository root and load configs/*.json.

Original CLI implementations are historical reference only. Their argparse imports
are intentionally preserved here; the new entry points do not parse command-line options.
Generated ROS/PlatformIO output and installed environments were left in their original
local directories rather than duplicated into this archive.
